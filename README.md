# PMX

Project Management Template.

PMBOKなどの知識を、実際のプロジェクトで使える「型」に落とすためのテンプレート集。

## Position

- **PM** — Project Management の知識・概念
- **PMX** — Project Management の実践テンプレート
- **editor-pm** — 編集・本づくりに特化したPM
- **make-book** — 本を実際につくるプロジェクト

## Flow

Pain → PRD → Requirements → Design → Mock → PoC → WBS → MVP → Implementation → Release → Feedback → Scale

## Core mapping

| PM concept | PMX |
|---|---|

| Deliverable | Deliverable |
| WBS | Work Breakdown Structure |
| Work Package | Issue |

| Milestone | Release |
| Dependency | Issue dependency |
| Risk | Possible future issue |
| Issue | Existing problem |
| Change Request | Change |
| Acceptance | Definition of Done |
| Lessons Learned | Retrospective |

## Principle

**PM = knowledge. PMX = reusable form.**

Project-specific domain knowledge belongs in a specialized project such as an editor/book PM repository.
